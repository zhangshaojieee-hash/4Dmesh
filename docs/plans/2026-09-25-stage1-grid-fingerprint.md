# 阶段一：模型绑定网格磁化

## 目标

让规则网格磁化数据明确绑定到创建它的模型，并在进入 4D 处理前拒绝模型替换导致的坐标错配。

## 验收参数

- 打印机配置：`prusa_i3_mk3`
- 网格尺寸：`5 mm`
- 磁化强度：`0.05 T`
- 磁化方向：`Z+`
- 测试模型：`test-duobianxing.STL`
- 预期网格尺寸：`[22, 22, 1]`
- 预期网格单元数：`484`

## 实现

- 临时模型上传接口返回原始模型文件的 SHA-256 指纹 `model_fingerprint`。
- 前端将指纹保存在 `SourceFile`，创建网格时写入 `GridMagnetization.modelFingerprint`。
- 网格同时声明 `coordinateSystemVersion: 1` 和 `exportTransformVersion: 1`。
- 后端在处理 4D 任务前重新计算模型文件 SHA-256；不匹配时返回 HTTP 409，并要求重新生成网格。
- 没有指纹的历史网格仍可使用，以保持旧项目兼容性。
- 重新生成网格时，仅在网格尺寸和模型指纹都一致时复用活动单元。

## 测试

- 匹配指纹通过校验。
- 不匹配指纹返回冲突错误。
- 没有指纹的旧网格继续通过校验。
- 5 mm 网格测试数据包含 `22 x 22 x 1` 和 `0.05 T / Z+` 活动单元。

## 未包含范围

本阶段不启动真实打印机，不改变 PrusaSlicer 配置，也不将测试模型或测试参数写入生产默认值。硬件执行须在后续阶段完成设备连接、干运行和急停验证后进行。
